Hosting

This site is hosted on GitHub Pages (GitHub, Inc., USA). When you visit, GitHub processes technical data such as your IP address to deliver the site and keep it secure. See the GitHub Privacy Statement. Legal basis: Art. 6(1)(f) GDPR (legitimate interest in running a website).

Terminal log

When you type a command into the terminal on this site, the following is saved:

  • the command you typed and the text the terminal showed in response
  • the time
  • a random session ID created in your browser, so commands from one visit can be grouped

Your IP address, browser details and location are not saved. The data is stored in a Google Sheet (Google Ireland Ltd. / Google LLC), which only I can access, and is used only to see how the terminal is used and improve it. Entries are deleted after 90 days. Please don't type personal information into the terminal. Legal basis: Art. 6(1)(f) GDPR.

Contact form

If you use the contact form, your name, email address and message are sent through FormSubmit to my email inbox, so I can reply. I keep them only as long as needed for the conversation. Legal basis: Art. 6(1)(b) and (f) GDPR.

No cookies or tracking

This site uses no cookies, no analytics and no advertising. Fonts are loaded from your own device, not from external servers.
