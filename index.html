About

A bit about me

I'm a Master's student in Computer Science (M.Sc. Informatik) at Hochschule Bochum, Germany. I like building software, automating workflows and solving problems that actually matter to people.

One of my favourite projects is the first OCR system for Kurdish (Badini & Sorani). It started because existing tools simply didn't support my language. I also enjoy writing clean backend code in Go and Python.

When I'm not coding, I'm probably learning something new or breaking (and fixing) my own setup.
